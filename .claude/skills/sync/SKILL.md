# /sync — GitHub同期

ローカルの状態をGitHub(origin/main)と完全に同期させます。

## 手順

1. `git status --short` で未コミット変更を確認する。
   - 変更があれば内容を確認し、意味のある単位でコミットする
     (メッセージ: `chore: <要約>` など。無関係な変更が混ざっていたら分けてコミット)。
   - `.env` やシークレットらしきファイルが含まれていたら**コミットせず**ユーザーに報告する。
2. `git pull --rebase` でリモートの変更を取り込む。
   - コンフリクトしたら `git rebase --abort` で戻し、状況をユーザーに報告して指示を待つ(勝手に解決しない)。
3. `git push` する。**`--force` は禁止。**
4. 結果を報告する: コミットした内容 / pull で取り込んだもの / push の成否。

## してはいけないこと

- `git push --force` / 履歴の書き換え
- コンフリクトの自動解決
- シークレットを含むファイルのコミット
