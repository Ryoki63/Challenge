## コンセプト

- 鉢に住む大福のような「タネの子」の**頭から植物が育つ**。体・顔・鉢は全段階で同じ(愛着が途切れない)
- **最初の双葉2枚 = ふたり**(自分の画面では左=自分・右=相手)。チェックインした人の葉がひらき、まだの人の葉は眠ってたたむ(就眠運動。しおれない・色も長さも変えない・外側に立てて中央の植物を隠さない)
- 段階2以降は**いつも「2本・2つ・2輪」が主役**。茎は葉の上でひとひねりして寄り添い、最終形では2本の茎のすき間がハート形になる「ふたりざき」。みのりではそのすき間に光るハートの「ふたりのタネ」
- ソロ(ペア前)は鉢のふちから寝顔がのぞく。ペア成立で目をさます(招待の動機)
- 線は暖かいこげ茶の単色アウトライン(小さい部品は細め)、塗りは2トーン+やわらかいハイライト(ステッカー調)

## 生成

```bash
python3 gen_layers.py     # layers/(34点)・composed/・svg/+png/(フォールバック)・preview_*.png・peek_offsets.json
python3 gen_icon_v4.py    # icon/(1024px)+ icon_compare.png
```

- `gen_v4.py` は部品ライブラリ(単体では実行しない)
- プレビューの PNG 化はヘッドレス Chrome(`/Applications/Google Chrome.app`)。SVG 自体は依存なし
- 決定論: 同じ入力から同じ SVG が出る(2回生成して全 SVG のハッシュ一致を確認)
- 生成時の自動チェック(失敗したら止まる)
  - 使う SVG 要素は path・基本図形・linear/radialGradient・opacity・transform のみ。filter・mask・clipPath・text・style・use・image・stop-opacity は使わない
  - 全レイヤーが XML として妥当
  - **左右の花の塗り(`petal_sN` とその左右反転)が1画素も重ならない**(塗りと線を別レイヤーにしても輪郭が透けない条件)
- 光(芽・土・のぞき・ハートのタネ)は stop-opacity を使わず、不透明度の低い同心円を重ねて描く(iOS の SVG 描画との差をなくすため)

## レイヤー(34点)

全レイヤーは同じ `viewBox="0 0 240 320"` に最終位置で描いてある。iOS は重ねるだけで座標を持たない。例外は3つ:

1. **右の葉・右の芽・右の花の塗り** = 左のレイヤー(`leaf_*` / `nub_*` / `petal_sN`)を x=120 で左右反転して使う。花の塗りを左右別に持つので、**v1.1 で2人が別々の花の色を選べる**
2. **のぞき(`fx_peek`)** = 中心 (120, 160) に描いてあり、段階ごとに下の表の分だけ平行移動する
3. **`bg_plate`** = ダークモードのときだけ最背面に敷く

| 種類 | レイヤー |
|---|---|
| 鉢 | `pot_back`(地面の影+鉢の口の土)/ `pot_front`(ふち+本体)— v1.1 の鉢の着せ替えはこの2枚を差し替える。ふちの寸法(y=222〜246、x=44〜196)は手・寝顔・土の光が依存するので固定 |
| 体 | `body` / `hands_rim`(ふちに掛けた手)/ `arms_up`(喜びのミトン型の腕)/ `solo_seed`(ソロ: 土の中で眠る。顔込み) |
| 顔 | `face_normal` / `face_happy` / `face_look_l`(ひらいた自分の葉を見る)/ `face_look_r`(ひらいた相手の葉を見る)/ `face_sleep`(すやすや)/ `face_wow`(段階アップ・はじめまして・おかえり) |
| ふたりの葉 | `nub_closed`(段階0: 閉じた芽)/ `nub_lit`(段階0: 背が伸びて先がひらき光る — 形でも区別)/ `leaf_open` / `leaf_folded`(段階1〜9共通) |
| 頭の植物 | `head_s2`〜`head_s9`(段階ごとに1枚。茎・葉・つぼみ・花の線と陰影。左右両方を含む) |
| 花の塗り | `petal_s6`〜`petal_s9`(**左の花だけ**・単色 `#FFB3C7`。アセットは元の色のまま入れ、iOS のコード側で着色する=着色し忘れても黒くならない) |
| 背面 | `bg_plate`(ダークモード用のクリーム色プレート) |
| 効果 | `fx_sparkle` / `fx_zzz` / `fx_celebrate` / `fx_soil_glow` / `fx_peek` |

## 独立レビュー(Opus max)の指摘と対応

| 指摘 | 対応 |
|---|---|
| H1 たたんだ葉が段階2〜4の植物を隠す(毎朝「縮んだ」ように見える) | 頭の植物を葉より上に重ね、ひとひねりを葉より上(y=88〜102)へ移し、たたむ角度を46°で外側へ。全段階×4状態の一覧を追加 |
| H2 段階9が散らかる(ハートが花と重なる・光が茎を濁らせる・小さなつぼみが巻き貝に見える) | ハートを茎のすき間へ下げて花と重ねない / 光は茎より下に描く / 小さなつぼみを削り、葉を1対増やす / 花を大きく(r=28) |
| H3 段階7で左右の冠が重なる | 傾きを10°に、先端の間隔を広げた。左右の塗りの重なりを画素で自動チェック |
| H4 花の色を左右で別にできない | `petal_sN` を左だけにし、右は反転して重ねる。花芯を琥珀色にして黄色の花びらと区別 |
| H5 ダークモードの方式が未定 | 背面プレート方式に決定し、ダークのプレビューを作成 |
| M1 段階0の光る芽が形で区別できない | 光った芽は背が伸びて先がふたつにひらく |
| M2 段階の差・視線が弱い | めばえはハートの芽を明確に、よりそいは先端が触れ合う形に、いろづきは色の面積を広げ割れ目の線を追加、視線を強めた |
| M3 たたんだ葉が「縮んだ」ように見える | 2つ折りのふっくらした形(幅38%)に変更。面積の差は承認時に確認してもらう |
| M4 プレビューと iOS の差 | 地面の影を `pot_back` に含めた / rect に ry を明示 / stop-opacity を廃止 |
| M5 文書の食い違い | 重ね順の正本を README に一本化。`gen_v4.py` から汗・垂れた葉・clipPath を使う旧関数を削除 |
| M6 フォールバック13枚で後退して見える | 段階ごとの sad(すやすや)を追加で生成。採用する場合は PlantSprite の sad 対応表を「同じ段階の sad」に直す |
| L2 腕がマラカスに見える | 太く短いミトン型に変更 |
| L3 小さい部品の線が太い | 小葉・つぼみ・冠の線を 3.2 に |
| L4 zzz がくすむ | 青みグレー `#8798AE` に |
| L1 のぞきの位置 | 「次に何かが出てくる場所」に段階ごとに配置 |
| L6 ウィジェットのメモリ / L7 着色の設定 / L9 開閉アニメ | iOS 実装時の注意として GROWTH.md §9.5 と取込タスクに引き継ぐ(ベクター保持を必須にし、合成済み画像の代替案を用意 / アセットは元の色のまま、着色はコード側 / 開閉はクロスフェードでなく拡大縮小や回転で) |
| L8 後半の段階ほど大きく見せたい | 今回は見送り(体と鉢の位置を全段階で固定する方針を優先)。G2 でユーザーの反応を見て判断 |
