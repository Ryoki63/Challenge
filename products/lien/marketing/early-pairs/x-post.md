# X の募集投稿(MK4 / issue #77)

公開日に一緒に始めてくれるペアを 5〜10 組集めるための投稿案。**下書きのみ**(投稿は mkt-lead 承認 → mkt-review レビュー → computer-operator)。

- 投稿の順番: X-1(本命)を投稿し、スレッドに X-3・X-4 をぶら下げる。X-2 は本命の代わりに使う物語版(両方は投稿しない)
- 応募は**この投稿への返信 / DM のみ**。プロフィールのリンクは使わない(公開前は飛び先が無い)
- 一次返信の文面は [`acceptance.md`](acceptance.md) §1
- 本文の原則は [`README.md`](README.md) §5。とくに **日付を書かない**(公開日は審査結果で動く)

## 0. 各投稿のフィールド

| フィールド | 意味 |
|---|---|
| `日付` / `投稿予定` | 投稿する日と時刻(Asia/Tokyo)。動かしてよい |
| `status` | `draft` → 承認後に `ready`。mkt-exec は `ready` にしない |
| `添付画像` / `代替テキスト` | 画像のパスと、X の「画像の説明」欄に貼る文 |
| `根拠` | 訴求の出どころ(`docs/*.md` の節) |
| `リンク先` | 公開前は「なし」。ストア URL は `<APP_STORE_URL>`(G0 後に確定) |
| `数値の根拠` | 本文に出した数字の説明。根拠の無い数字は書かない |
