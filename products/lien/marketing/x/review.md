## 4. リスク点検（景表法・誇大表現・その他）

| 論点 | 判定 | 対応 |
|---|---|---|
| 優良誤認（実際より良く見せる） | OK | 機能は REQUIREMENTS の実装済み範囲のみ。比較級・最上級を使わない |
| 有利誤認（価格・条件） | OK | 「いまは全部、無料で使えます」のみ。将来の価格に触れない |
| 誇大表現 | OK | 「絶対」「必ず」「日本一」「No.1」「唯一」「業界初」を使わない（検査対象） |
| 体験していない機能の訴求 | OK | 開発者自身が実機で確認していない画面は「指定」として画像だけを留保し、本文では断定しない |
| 競合への誹謗・比較 | OK | サービス名を出さない（TASKPLAN §9.4 の Pairy 語全廃に合わせる） |
| 商標 | OK | 「X」「App Store」「iPhone」「iOS」は事実の記述として使用。ロゴ画像は使わない |
| 日付の断定 | OK | 本文に日付・年を書かない（検査対象）。公開日告知は公開確認後 |
| プライバシー | OK | 実在の人物・写真・ニックネームを使わない。デモ名のみ |
| 画像の権利 | OK | 自社制作のアート（`products/lien/assets/`）と自社の実機スクリーンショットのみ |
| 医療・健康の効果 | 該当なし | 習慣の継続を扱うが、健康効果・治療効果をうたわない |

## 6. 却下した表現（再発防止）

| 表現 | 理由 |
|---|---|
| 「サボった日、アプリに何と言われたいですか」 | 「サボ」はアプリ本体の禁止語（`StringsReviewTests.PunishmentFreeLint`）。投稿でも使わない |

| 「必ず続く」「誰でも続く」 | 効果の保証（誇大表現）。実測もない |
| 「Pairy の代わりに」 | 競合名の利用（TASKPLAN §9.4 の方針）。乗り換え層には「サービス終了後に、次の習慣アプリを探している人へ」と書く場合も、名前は出さない |
