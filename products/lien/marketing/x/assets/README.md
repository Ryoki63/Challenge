# x/assets/ — 投稿に添える画像の置き場

このフォルダには、**実際に X へ投稿する画像だけ**を置く。既存のアート（`products/lien/assets/`）は複製しない（二重管理を避けるため、投稿案からは元のパスを直接指す）。

## 命名

`YYYY-MM-DD-<用途>.png`（投稿案のファイル名と揃える）

例:

- `2026-10-23-home.png` — ホーム画面の実機スクリーンショット
- `2026-10-24-checkin.png` — チェックイン完了直後
- `2026-10-25-widget.png` — ホーム画面のウィジェット
- `2026-10-26-notification.png` — ロック画面の通知
- `2026-10-31-store.png` — App Store の1枚目
- `2026-11-01-home.png` — ホーム画面 + ウィジェット
- `2026-11-07-share.png` — シェア画像の見本（デモデータ）

## 作るときの約束

- 実在の人物・連絡先・写真を写さない。デモ名は「あおい」「ゆうき」だけ（`../screenshots/plan.md` §2）。
- 旧画風の SVG 下絵（`../screenshots/6.7in/`）は使わない。現在の画面を実機で撮り直す。
- サイズは X の推奨に合わせる（横 1600×900 / 正方形 1080×1080）。PNG。
- 文字が潰れていないか、最大の文字サイズでも欠けないかを確認する。
- 画像を置いたら、投稿案の `添付画像` をこのパスに差し替え、`代替テキスト` を実際の画に合わせて直す。
- 差し替え後に `python3 ../tools/check_posts.py` を実行する（パスの実在と、`指定:` のまま `ready` になっていないかを検査する）。
