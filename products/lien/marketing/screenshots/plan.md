# App Store スクリーンショット設計書(T26 / issue #26)

G4(ストア素材承認)レビュー用。実機スクリーンショットはまだ無いため、
本書 + SVG 下絵(`6.7in/` `6.1in/`)が「構成の正本」。
実装が進んだら、各 Frame の指定どおりに撮影して SVG の `device-placeholder` 枠へ差し込む。

- 正本: REQUIREMENTS §0(アプリ名 Lien・ネオドット絵)/ CONCEPT §5(罰を使わない)・§7(ASO最優先)
- コピーの原則: **罰・恥・焦らせる表現を使わない**。「約束はひとつだけ・静か・ふたり」を一貫させる

## 1. 書き出しサイズ(App Store Connect 必須セット)

| 通称 | px(縦) | 対象 | 備考 |
|---|---|---|---|
| 6.7インチ | **1290×2796** | iPhone Pro Max 系 | 必須。6.5インチ要求にも流用可 |
| 6.1インチ | **1179×2556** | iPhone 無印/Pro 系 | 6.7のみでも代用されるが、最適化のため両方用意 |

- 各サイズ 5枚(App Store は最大10枚。まず5枚で出し、検索結果に見える**1〜3枚目が勝負**)
- フォーマット: PNG または JPEG、アルファなし

## 2. 共通トーンとデモデータ規定(全フレーム共通)

| 項目 | 規定 |
|---|---|
| 背景色 | `#F4EFE6`(植物スプライトの contact_sheet と同一のオフホワイト) |
| 見出し色 / サブ色 | `#3A2C28` / `#6B4A36`(スプライトの輪郭・土の色) |
| フォント | ヒラギノ丸ゴ ProN(なければヒラギノ角ゴ)。丸み=罰のないやさしさ |
| 装飾 | 植物ドット絵(`assets/plant/` と同一データから SVG 化済み)。1枚に1株まで |
| デモ名 | 自分 = **あおい** / 相手 = **ゆうき**(REQUIREMENTS §3.12 の通知例と一致) |
| 約束 | あおい「筋トレ💪」 / ゆうき「ランニング🏃」 |
| ストリーク | **23日**(§3.12「ふたりの23日」と一致。育成途中=これからが伝わる数字) |
| 植物 | stage3 若葉(成長途中が最も説得力がある)。Frame 1 のみ happy 差分 |
| 時刻表示 | シミュレータは 9:41 固定(Apple 慣例)。通知系 Frame 4 のみ 20:00 台が自然 |
| 写真 | 実在人物・個人情報の写り込み禁止。チェックイン写真はサンプル静物(例: ランニングシューズ) |

## 3. 5枚構成(コピーは SVG と同一。変更時は tools/gen_screenshot_svg.py の FRAMES を直す)

### Frame 1 `01_promise` — フック「約束は、ひとつだけ。」
- 目的: 検索結果の1枚目。コンセプトを3秒で伝える
- バッジ: 約束はひとつ / アクセント: ピンク `#F69AC0`
- サブコピー: ふたりで決めて、毎日つづける習慣アプリ
- 差し込む実機画面: **ホーム画面**。植物(stage3 happy)+ふたりの今日(あおい○/ゆうき○)+ストリーク🔥23
- 見せ場: 画面の情報が「植物・2人の状態・日数」の3つしかないこと自体がメッセージ

### Frame 2 `02_widget` — 主役機能「相手の今日が、ホーム画面でわかる」
- 目的: 差別化の核(ウィジェット)を2枚目で見せる
- バッジ: ウィジェット / アクセント: グリーン `#59C165`
- サブコピー: チェックインすると、相手のウィジェットがすぐ更新
- 差し込む実機画面: **iOSホーム画面**に S ウィジェット(2人の○×+🔥23+植物)と M ウィジェット(+相手の今日の写真)を設置した状態
- 撮影注意: 壁紙は無地系(背景 `#F4EFE6` に馴染む明るい壁紙)。他アプリのアイコンが写る場合は標準アプリのみにする

### Frame 3 `03_checkin` — 体験の軽さ「『やった!』は1タップ」
- 目的: 「面倒じゃない」ことの証明。習慣アプリ離脱理由の第1位は記録の手間
- バッジ: 1タップ / アクセント: イエロー `#FFD966`
- サブコピー: 写真をそえると、相手のウィジェットに届く
- 差し込む実機画面: **チェックイン完了直後**(完了演出+キラキラ、写真添付ボタンが見える状態)

### Frame 4 `04_poke` — 継続の仕掛け「通知は、相手の名前で届く」
- 目的: 「アプリの通知は無視しても、相手からの通知は無視できない」を見せる
- バッジ: つつく / アクセント: ブルー `#7EC8F5`
- サブコピー: 「そろそろやろ?」のひと言で、今日もつづく
- 差し込む実機画面: **ロック画面の通知**2件 — 「ゆうき: そろそろやろ?👀」(つつき)/「ゆうき: ランニングやった!🔥」
- 撮影注意: 通知の文言は §3.12 の表どおり。責める・急かすトーンの文言は使わない

### Frame 5 `05_ticket` — 安心設計「できない日があっても、だいじょうぶ」
- 目的: 罰なし設計(CONCEPT §5)を安心材料として提示。ストリーク不安への先回り
- バッジ: お休みチケット / アクセント: テラコッタ `#E89A60`
- サブコピー: お休みチケットが、ふたりのつづきをまもる
- 差し込む実機画面: **カレンダービュー**(月表示。ふたり達成の日+お休みチケットで守られた日が見える)
- 撮影注意: しょんぼり植物・未達の強調は使わない。「守られた」事実だけを見せる

## 4. 制作手順(実機スクショができたら)

1. シミュレータ iPhone 16 Pro Max(1290×2796)/ iPhone 16 Pro(1179×2556)で各 Frame の状態を再現し、`xcrun simctl io booted screenshot` で撮影
2. SVG をエディタで開き、`<g id="device-placeholder">` の中身を `<image>`(撮影PNG)に差し替え、角丸はそのまま流用
3. PNG 書き出し: Figma / Sketch に SVG を読み込んで書き出すのが確実(フォント環境が揃うため)。CLI なら `rsvg-convert` や `qlmanage` でも可だがフォント検証必須
4. 書き出し後の検証: 寸法が表1と一致 / アルファなし / 文字切れなし / 1〜3枚目だけ見てもコンセプトが通じるか

## 5. 再生成

```
python3 tools/gen_screenshot_svg.py
```
コピー・色・構成を変えるときはスクリプト内 `FRAMES` を編集して再生成する
(SVG を直接編集した場合、再生成で上書きされるので注意)。
