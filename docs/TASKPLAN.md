## 4. 並列実行ガイド

- ループ自体は 1回1タスクの直列。並列にする方法は2つ:
  1. **マシン分担**: Windows ループが [W] を消化している間、Mac の対話セッションで [M] を進める(同じ main ブランチに pull/push。タッチするディレクトリが違うので衝突しない)
  2. **セッション内fan-out**: 互いに独立なタスク群({T15〜T19} など)は、対話セッションから Agent ツール(worktree 分離)で同時進行できる
- 衝突回避の原則: **同時に触ってよいのは別ディレクトリのタスクのみ**(ios/ ∥ supabase/ ∥ assets/ ∥ marketing/ は常に安全)。`Strings.swift`・`project.yml`・migration 連番を触るタスクは直列にする
- ゲート待ちで [W] が枯れたら: 先のフェーズの [W] タスク(T25, T26 など依存の薄いもの)を前倒しして積む
