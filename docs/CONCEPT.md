# ふたり習慣(仮称)— 企画決定レポート

- 作成日: 2026-06-10
- ステータス: **開発決定**(MVP着手前)
- 最新の確定仕様は [REQUIREMENTS.md](REQUIREMENTS.md)。本書と差異がある場合はそちらを優先
- ゴール: このアプリ単体で **月3万円** の継続収益

> **TL;DR** — 「大切な人と約束を1つだけして、ふたりで続ける」習慣アプリを作る。
> 2人ストリーク(Snapchat/Duolingo型)× 相手の状態が見えるホーム画面ウィジェット(Locket/Widgetable型)× 罰なしの共同育成(Finch型)。
> ペアで月480円のサブスク、63ペアの課金で月3万円に到達する。

---

## 1. ゴールと経緯

- 目標は個人開発アプリでの月3万円。広告モデルは月数十万PVが必要で非現実的なため、**「100人が月300円払いたくなる熱量のニッチ」を課金で取る**方針。
- AI時代に代替されないアプリの条件として以下を定義した:
  1. **蓄積** — 自分(たち)のデータが溜まるほど離れられない
  2. **速さ** — AIに聞くより速い、3タップで終わる
  3. **愛着と相手** — 推し・ペット・約束の相手など、人やキャラクターが組み込まれている
- 候補5案(推し活おこづかい帳 / ふたり習慣 / サークル出欠+集金 / 同人頒布管理 / 縦書きエディタ)から**案2「ふたり習慣」に決定**(2026-06-10)。
- 以前の検討で選んでいた「2人用ウィジェット」(Locket型)の方向性は、本案に統合された(ウィジェットがコア機能の一部になる)。

## 2. プロダクトコンセプト

**一行コンセプト**: 「ふたりで、約束をひとつだけ。」

**コアループ(1日3タップ以下)**:
1. それぞれが自分の約束を1つだけ決める(同じでも違ってもいい) — 筋トレ、英語、禁酒、早起き、何でも
2. やったら1タップでチェックイン(写真を添えるのは任意)
3. **相手のホーム画面ウィジェットに即反映** — 「相手はもうやった」が見える
4. 両方やった日だけ「ふたりのストリーク」が伸び、2人で育てている生き物(植物)が育つ
5. 相手がまだなら「つつく」— 通知はアプリ名ではなく**相手の名前**で届く

**対象ユーザー**: カップル限定にしない。恋人・夫婦・友達・親子・きょうだい。将来的に1ユーザーが複数の「ふたり」を持てる設計にする。

## 4. 市場の空白(ポジショニング)

- Widgetable → 「つながり」はあるが「習慣」がない。広告多・課金高・多機能化で不満蓄積中
- Finch → 「習慣×育成」だが1人用
- みんチャレ → 「習慣×仲間」だが5人で重い
- HabitShare → 「習慣×2人」だが愛着ゼロ・英語のみ・無料放置
- **Pairy → 2026年6月30日サービス終了確定(2026年4月発表)。数十万人のユーザーが乗り換え先を探している**

→ **「2人 × 習慣 × ウィジェット × 日本語」が空き地。さらにPairy終了により今月末に乗り換え需要が発生する。**

### 参入タイミング評価

**Pairyの終了は最大の参入窓口**: カップルアプリとしてのPairyユーザーベースは400万人以上。サービス終了告知から乗り換え検討中のユーザーがいる状態で、App Storeに「日本語の2人用アプリ」が存在していれば自然流入が期待できる。TestFlight配布をPairy終了前後に合わせるだけで初期の口コミが生まれやすい。

## 5. 設計原則(決定事項)

1. **罰を使わない**(Finchの教訓) — サボっても生き物は死なず、しょんぼりするだけ。「切れたら終わり」ではなく「お休みチケット」で守れる。Snapchatストリークの不安・強迫の副作用を回避する
2. **カップル限定にしない** — 解散=チャーンのリスク緩和。友達・家族にも開く
3. **通知は相手の名前で届ける** — Duolingoの+22%の核。アプリからの通知は無視されるが、相手からの通知は無視できない
4. **招待が構造的に必須** — 1人では使えない=全ユーザーが宣伝係(Locketの成長の正体)
5. **機能を増やさない** — Widgetableは多機能化と攻撃的な課金導線で不満を持たれ始めている。「約束1つだけ、静かでシンプル」という逆張りがそのまま差別化
6. **招待だけに頼らない** — Lapseの教訓。招待制でバイラル成長しても、リテンションがなければ翌月70%減。ストリーク×育成×ウィジェットで「毎日見る理由」を作ることがバイラルより重要

## 6. 課金設計と月3万円の算数

| プラン | 内容 |
|---|---|
| 無料 | 1ペア・習慣1つ・基本ウィジェット |
| プレミアム(個人で月700円 / 年2,400円。課金者が属する全ペアに適用) | ストリーク保険(お休みチケット増量+繰越)、植物の品種・着せ替え、写真アルバム無制限、ウィジェットテーマ、(v2)複数ペア最大5 |

- 月3万円 = **売上ベースで課金者43人**(1ペアに課金者は1人いれば足りるので≒43ペア)。Apple手数料15%(Small Business Program)控除後の手取りベースなら**約51人**
- 以前の月480円から**月700円/年2,400円**に改訂(2026-06調査より): グローバル中央値は月$12.99・年$38.42。Widgetableの日本実績は月¥700〜400。1人あたり月350円は安すぎず・高すぎない帯
- 課金の柱は**ストリーク保険**(Duolingoで実証済み — 「切らしたくない」心理が一番財布を開く)
- **17日以上の無料トライアル**を設定: グローバルデータで42.5%転換(短期比70%改善)。v1.0は全機能無料で習慣形成させ、v1.1でペイウォール導入
- **課金タイミング**: 転換の約50%がDay 0(インストール当日)。オンボーディング完了時に年額プランを提示するA/Bテストを優先
- StickK型の「賭け金」機能はv2以降。日本では資金決済法に抵触しうるため、現金を預かる設計はしない

### 月3万円の現実性評価(2026-06調査より)
- 新規サブスクアプリの1年後中央値: 約$72/月(≒10,800円)
- 月$200(≒3万円)達成は全体の上位25%圏内 — 普通より少し頑張れば届く
- 月$1,000(≒15万円)達成は全体の17.3% — Quittr/Cal AIはここを初月から超えた
- **Pairyユーザーの流入タイミング**を捉えれば、中央値超えを初期から狙える

## 7. 拡散ループ(集客ゼロからの戦略)

1. **招待必須設計** — 使い始めるには必ず1人誘うことになる
2. **節目のシェア画像** — ストリーク30日・100日達成などで「ふたりの記録」画像を自動生成 → X / Instagramストーリーズへ
3. **開発の物語** — 「なぜ作ったか」をXで発信(Locketは物語自体がマーケティングだった。Cal AIは281本のオーガニック動画が有料広告ゼロでの立ち上げを支えた)
4. **Pairy終了タイミング狙い** — 2026年6月30日のPairy終了に合わせてTestFlight配布開始。Pairyのキーワード検索でヒットするようASO設定
5. **ASO最優先** — DLの65%超がストア検索経由。「ふたり習慣」「カップル」「2人で」等の日本語ロングテールキーワードを初日から設定

## 9. 技術方針

- **iOS先行**(日本の課金率・ウィジェット文化ともにiOS優位)。Android版はiOSで収益が立ってから(v2+)
- 開発機にMacがあるため、**ネイティブ SwiftUI + WidgetKit** を採用(2026-06-10更新。当初Windows前提でExpo+EASを検討したが撤回)
  - ウィジェットが主役のアプリなので、WidgetKitを直接扱えるネイティブが最適。ロック画面ウィジェットやLive Activityへの拡張も素直にできる
- バックエンド: Supabase(Auth + DB + Realtime + Storage)。プッシュ通知はAPNs(Supabase Edge Functionsから送信)
- 課金: RevenueCat(サブスク管理の定番、無料枠で十分)
- 固定費: Apple Developer Program 約12,800円/年、Supabase無料枠、合計で月1,000円強

## 10. リスクと対策

| リスク | 対策 |
|---|---|
| Widgetable本家が習慣機能を追加してくる | 「約束1つだけ・静か・日本語」の逆張りポジションを維持。機能競争に乗らない |
| ペア解消(別れ・疎遠)によるチャーン | カップル限定にしない。ペアの「引き継ぎ」「新しい相手と再開」動線を用意 |
| ウィジェットの更新遅延(WidgetKitはタイムライン更新に制約がある) | サイレントプッシュ受信時に WidgetCenter で再読み込みする設計。「相手がやったら1分以内に反映」を目標値にする |
| App Store審査(2人いないと使えないアプリ) | 審査ノートにテストアカウント2組を添付+1人でも触れるデモモードを用意 |
| 無料のHabitShareの存在 | 日本語圏では実質競合不在。愛着(育成・ウィジェット)で機能面でも上回る |
| Pairy終了後のユーザーを取りにいけない | TestFlight配布をPairy終了(2026年6月30日)前後に合わせ、ASOキーワードにPairy関連語を含める。6月末〜7月が最大の集客窓口 |
| バイラル成長後にリテンションが伴わない(Lapseの轍) | v1.0の時点でストリーク+ウィジェット+育成の3点セットを揃えてからリリース。DL数よりDay 30継続率を最初のKPIにする |
