## 決定の返し方

Issue #119 に、次のいずれかを返信する（秘密・認証情報・個人の連絡先は書かない）。

- `A` — 個人アカウント + テスター 15〜20 人を募集（推奨。11/13 に 12 人の見込みがなければ B へ）
- `B` — 組織アカウント（D-U-N-S）。個人事業主の開業・事業用住所/電話/ドメインが必要
- `C` — 保留（iOS v1.1 の後に再判断）
- 予算は `A` なら「広告 0・端末借用」、`B` なら「上限増額」、`C` なら「延期」を添える

判断カードの `status` は、決定後に `accepted` / `rejected` へ更新し、`decided_at` / `decided_by` / `decision` を記入する。このリポジトリのエージェントは、外部送信・支払い・ストア申請を行わない。
